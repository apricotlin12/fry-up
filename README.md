# 薯條向上！ FRY UP

薯條逃離油鍋的復古網頁小遊戲，支援鍵盤及手機觸控。

在此資料夾執行 `node server.cjs`，瀏覽 http://127.0.0.1:4173 。也可直接開啟 dist/index.html。

左右方向鍵或 A / D 移動；空白鍵開始、暫停或重新開始。手機使用畫面下方按鈕。

薯條自動跳躍，綠色平台有加強彈力，餅乾平台踩一次就碎裂。熱油持續上升，難度隨樓層增加。最高樓層儲存在瀏覽器。

本機新版另有黑色油垢踏板：落地後先沿板面滑行 0.24 秒，仍在板上才自動跳起；滑出邊緣則往下掉。保留原本的橫向慣性，鬆手幾乎不減速，但按反方向能主動煞車。垂直落下不會自行滑動，落到乾燥踏板會恢復抓地力。踏板大小各異，餅乾同層的乾燥備援踏板也會隨大小調整距離。

整體速度每 50 層提升，且每段加速量比上一段多 0.05：依次增加 0.05、0.10、0.15、0.20 倍。50 層為 1.05 倍、100 層為 1.15 倍、300 層為 2.05 倍、400 層為 2.80 倍、500 層為 3.75 倍，沒有速度上限。移動、跳躍、油鍋、粒子與動畫都共用同一個加速時鐘，跳躍距離不變。畫面顯示實際速度倍率和隨加速增強的速度線。物理採用小時間步，避免高速時穿過踏板。

油鍋完全離開畫面後，會隨機抽取 5～15 層的反撲門檻。往上達到抽中的新樓層數，熱油會湧回畫面、短暫停留，再退到畫面底部；上湧高度與實際沉寂的層數成正比，每層為 20 像素（5 層 100、10 層 200、15 層 300）。再次消失時重新計數及抽選。反撲的熱油仍會造成傷害，動畫跟隨整體速度，暫停時也會停止。

每局開始有 0.01%（萬分之一）機率，角色變成裝著三根薯條的油炸網，自帶三條命。每次失去生命會少一根薯條，返回安全平台並有兩秒保護時間；三條命耗盡才結束。一般薯條仍然是一條命。暫停與繼續不會重新抽選角色。

## GitHub Pages

使用 `main` 分支的根目錄 `/ (root)` 作為 Pages 來源。根目錄的 `index.html` 會導向 `dist/` 中的遊戲，`.nojekyll` 讓 GitHub 直接提供靜態檔案。

所有遊戲邏輯都在瀏覽器執行，不需要建置或後端伺服器。
